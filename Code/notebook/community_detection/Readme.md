# Community detection

Questo modulo raccoglie diversi algoritmi per individuare le comunità presenti in un grafo di utenti. Il file di ingresso è `main.py`, che calcola le partizioni e produce statistiche e grafici.

Esecuzione di base:

```bash
python main.py
```

L'opzione `--force` permette di sovrascrivere eventuali risultati già presenti. Tutti gli output vengono conservati nella cartella `output/`. Per consultare le visualizzazioni è sufficiente avviare un semplice server locale (ad esempio `python -m http.server`).
